# 德州扑克学习训练器

本地运行的中文新手学习软件，包含「跟着学」「针对练」「模拟比赛」三个入口。

## 启动

```bash
cd /Users/admin/Documents/DMP/holdem-trainer
npm install
npm run dev
```

浏览器访问 `http://127.0.0.1:5173/`。开发服务器只监听本机地址，不依赖远程服务。

## 模拟规则

9 人桌，每人 1000 筹码，60 分钟；盲注依次为 20/10、40/20、80/40、100/50，前三名积分 30/20/10。前注、最后一手结算和同筹码排名属于待确认项，开始模拟前必须勾选训练假设。

比赛进度和练习错题保存在浏览器 `localStorage`，刷新页面可恢复比赛。

## 校验

`npm test` 运行规则核心测试，`npm run build` 构建生产文件。

## 其他电脑使用

安装 Node.js 22.12 或更新的 LTS 和 Git，然后执行：

```bash
git clone https://github.com/wenbofan0515-afk/holdem-trainer.git
cd holdem-trainer
npm ci
npm run dev
```

训练记录仅保存在当前电脑和当前浏览器，不通过 GitHub 同步。

## Codex Skill

将仓库的 `skills/holdem-trainer` 文件夹复制到 `~/.codex/skills/`，重新开启 Codex 会话，然后输入 `$holdem-trainer 启动训练器`。

## 一手训练与复盘

开始前确认训练假设，点击「开始 / 继续」。按钮显示实际跟注差额、加注目标和全下金额；下注输入框填写本轮累计目标。暂停时按钮禁用，刷新后暂停恢复，不重新扣盲。

一手结束后自动派奖，并显示你的各次行动、当时底池、跟注价格和筹码净变化。跟注价格只是最低权益门槛，不是实际胜率，也不是策略评分。最近 20 手复盘保存在本机。默认自动继续下一手，轮转庄家和盲注并沿用筹码；可取消自动继续，暂停查看复盘。

## 验证与范围

规则测试覆盖差额跟注、最小加注、短全下重开、边池、未跟注退款、平局、A 小顺、双人行动顺序及固定种子连续模拟中的牌不重复与筹码守恒。使用 MIT pokersolver 比较摊牌。

当前仅 5 道练习，电脑是基础练习对手。已支持完整 60 分钟赛程、到点完成最后一手、最终筹码排名和前三积分；专业策略评分和胜率求解不在当前范围。前注、到点最后一手和并列积分仍是待确认规则。旧版牌桌存档无法兼容，将创建新牌桌；新版可刷新续局。

## 整场比赛与结果

正式时长 60 分钟，5 倍速训练同步加速比赛与升盲时钟，新盲注从下一手生效。到点不再发新手，当前手完成派奖后显示九人最终筹码排名；只剩一人则提前结束。用户淘汰后可快速观战。

未并列的前三名依次为 30、20、10 分。并列采用占位名次（如 1、2、2、4）作训练展示；涉及前三的并列积分标记待确认，不自行分配。此规则仍待主办方确认，不按淘汰顺序决定名次。最近 10 场结果保存在本机，刷新可恢复；关闭或刷新期间暂停，后台打开时按实际经过时间计时。
