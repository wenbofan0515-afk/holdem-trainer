# 十轮优化记录

本批按用户授权依次改进回放、操作衔接、学习重点，随后完成其他学习体验改进。各轮在独立 Git 提交中保留变更。验证使用隔离数据，不操作用户 5173 存档。

1. 回放更直观：九位玩家标记当前行动者，阶段按钮标记当前轮，新发公共牌以金色边框和文字双重提示。
2. 操作衔接：复盘练习改为比赛内切换，返回保留本次规则确认、倍速、回放进度和展开状态；时钟保持暂停，焦点返回入口，不重扣盲注。
3. 学习重点：主页新增四类知识进度和最多四题推荐，优先当前错题再未答题；明确最近答案统计不代表实战胜率，损坏和越界记录过滤。
4. 高效回放：新增“只看我的决策”和行动定位下拉框，前后导航跳过电脑动作但保留真实原序号，结算始终可达。
5. 重点与题目精确对应：每条重点可单独进入两道对应练习；整手巩固题从展示的两个重点中选取，避免被早期无关动作占满。
6. 练习结果更明确：显示本组得分、正确率和完成进度，可只重练本组错题；返回按钮按实际入口区分首页、复盘或上一页。
7. 练习中断续接：本机保存题组、位置、已提交答案和本组成绩，下次明确选择继续或重新开始；不同指定题组不混用，损坏记录不恢复。
8. 操作状态防混淆：新轮次、新行动者或新手时清空旧下注目标；修改金额后取消旧全下确认；刚好用尽筹码的跟注也标明全下，辅助大盲数按本手盲注解释。
9. 分步教学：将静态概览升级为六步可重播流程，逐步展示0/0/3/4/5/5张公共牌、独立合法操作例子和最终最强五张，并可进入规则巩固题。
10. 历史复盘快速定位：最近20手改为下拉选择、一次只展示一手，区分比赛标识、手数和净变化；减少重复回放控件，增加清晰的键盘焦点样式。

## 最终验收

- 自动化：9 个测试文件、61 项测试通过；覆盖规则、赛程计时、界面完成四轮下注、复盘往返、练习续接及历史选择。生产构建通过。
- 实际内置浏览器：使用独立 5176 端口及隔离数据，走通六步教学至最强五张；完成手即时复盘、仅本人决策筛选、跳至结算、进入对应两题练习、作答、返回、再次进入并明确续接。
- 返回后核对：960 筹码不变、比赛暂停、规则确认保留、回放仍在最终结算且本人筛选勾选保留；历史区一次显示所选一手。
- 390 像素窄屏截图检查：文字换行可读，复盘表格在容器内横向滚动。未操作用户 5173 页面或存档。
