# 回放与定向练习验收

## 本轮改动

1. 全额下注或加注和全下、耗尽筹码的跟注一样，需要确认，取消不扣钱。
2. 每手复盘新增只读动作回放：上一步、下一步、各轮跳转、最终结算；使用每条记录的当时公共牌、底池、跟注差额与投入，不重新运行引擎。
3. 复盘新增最多 4 道对应知识巩固题；沿用 20 题题库和错题本，可返回原手复盘。不会把练习映射当成策略错误诊断。
4. 修正 README 中默认自动下一手、题库数量、已移除跳转按钮的旧说明。

## 范围说明

回放不是重新计算整桌历史筹码的动画，也没有未记录的真实思考耗时；显示已有动作记录。返回比赛仍需确认训练假设后才可继续。完整 60 分钟赛程采用自动化加速验证，本轮未人工等待 60 分钟。策略建议不使用对手隐藏底牌，也不声称为专业求解器评分。
