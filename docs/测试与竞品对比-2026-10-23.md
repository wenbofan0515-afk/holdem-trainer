# 德州扑克训练器：操作测试与竞品对比

测试日期：2026-10-23。基线：d4c6aa3。环境：本机 macOS、Codex 内置浏览器、React/Vite。使用独立端口 5176、独立测试存档；未改动用户 5173 存档。

## 结论与覆盖范围

真实浏览器已点通跟注、过牌、下注、加注、弃牌、全下；完成一手四轮下注、派奖、复盘、下一手；测试暂停、速度切换、辅助、取消重开及非法金额。未出现阻塞或错误提示。

新增六种动作按钮集成测试，校验动作记录、筹码守恒、弃牌状态及全下余额。33 项自动测试通过。原有比赛测试覆盖到点最后一手、最终排名、并列争议积分、暂停刷新及升盲边界。本轮没有人工等待完整 60 分钟；这些边界由模拟时钟测试验证。

尚未逐项完成的浏览器覆盖：快速观战切回、历史比赛展开、确认重开、全应用每道练习题、窄屏全部分支。本报告不将其计为已实测通过。

## 操作步骤与时间

计时为捕获 click 到两次 requestAnimationFrame 的近似绘制延迟，包含约两帧等待；不是严格端到端性能指标。每个场景一个样本，过牌三次，不含读题、思考、输入和自动化工具往返。后台标签与机器负载影响结果，不能当作性能保证。原始记录见 action-timing.json，其中 controls 包含前一场累计记录，不应重复计数。

| 操作 | 从轮到自己开始的步骤 | 点击次数 | 近似绘制延迟 |
|---|---|---:|---:|
| 开始 | 勾选接受 → 开始/继续 | 2 | 开始按钮 11.8–16.0 ms |
| 跟注 | 查看补齐金额 → 跟注补20 | 1 | 10.3 ms |
| 过牌 | 确认无需补钱 → 过牌 | 1 | 11.5 / 13.1 / 36.9 ms |
| 下注 | 查看最小20 → 下注到20 | 1（用默认金额） | 15.5 ms |
| 加注 | 金额框输入40 → 加注到40 | 1次输入＋1点击 | 15.7 ms（不含输入） |
| 弃牌 | 弃牌退出本手 | 1 | 18.3 ms |
| 全下 | 全下1000 | 1 | 10.5 ms |
| 复盘底牌 | 展开摊牌玩家底牌与牌型 | 1 | 18.2 ms |
| 完整记录 | 展开完整行动与结算记录 | 1 | 11.4 ms |

| 重开取消 | 重新开一场 → 取消 | 2 | 9.9 / 12.8 ms |

输入金额1时，显示“请输入范围内的整数”，加注禁用；跟注和弃牌仍可用，恢复40后能成功加注。

电脑等待是代码设定：正常每次450 ms，快速观战60 ms；正常自动接手2000 ms、快速100 ms。9人全部在场时，8个电脑依次行动的设定等待约3.6秒，尚不包含渲染开销，**不是本轮精密测量值**。人工阅读时间未测，不以操作脚本耗时冒充。

完整一手示例（种子456）：跟注20 → 翻牌过牌 → 转牌过牌 → 河牌过牌 → 派奖。共36次全桌行动，用户4次决策；底池180由电脑1同花赢得，用户1000变980。复盘有4条用户记录及11.8%跟注最低权益解释。继续下一手成功。全下场景也完成结算，用户1000变0，显示淘汰观战入口。

## 清晰度与真实缺口

- 开始路径清楚：未接受假设不能启动，有文字指引；电脑行动时明确不用点。
- 跟注补差额、加注本轮累计金额、最小/最大金额均可见，但金额含义仍需要新手阅读长句。
- 操作区位于牌桌下，可能需要滚动；“前往我的操作”能跳转，建议固定操作栏。
- 默认2秒自动下一手容易错过复盘，学习模式应默认手动继续。
- 弃牌、全下立即执行；全下可增加轻量确认和投入后剩余筹码预览。
- 边池结算日志重复显示同一赢家多笔金额，建议按主池/边池明确标注。
- 当前教学是4个静态步骤，并非逐步互动发牌；题库只有5题，未达到原计划20题。
- 错题只在“下一题”时保存，退出前可能漏存；没有加载错题与重练入口。
- 电脑策略主要依赖底牌，缺少结合公共牌的决策；不能将战胜电脑等同实际水平提升。

## 相似产品公开资料对比

以下均于测试日访问官网，未登录或体验付费功能；产品宣称不作为独立效果证明。

| 产品及来源 | 官网明确展示的功能 | 对本项目有用的借鉴 |
|---|---|---|
| [GTO Wizard](https://gtowizard.com/) | Study / Practice / Analyze；自定义训练、即时反馈、牌谱分析、进度统计 | 从复盘某个决策直接进入相同条件重练，按主题归类薄弱项 |
| [DTO Poker](https://www.dtopoker.com/) | 区分现金桌与锦标赛；强调简化下注尺度；锦标赛训练器与Explorer | 围绕本场9人、限时筹码排名设置专门场景；用少量合法快捷金额减少输入 |
| [PokerCoaching](https://pokercoaching.com/) | 引导课程、手牌测验、每日练习、即时反馈、薄弱点对应学习内容 | 错题 → 简短知识解释 → 重练 → 进度的学习闭环 |

这些产品通常使用求解器或专业策略库。本项目的限时排名规则与标准锦标赛不同，不可直接照搬其ICM答案，也不能给当前基础电脑包装GTO评分。

## 建议顺序（本轮未实施产品改动）

1. **先修学习闭环**：默认手动下一手；答题即保存；错题入口与重练；补足并审核20题。验收：退出恢复不丢答案，复盘读完前不自动离开。
2. **减少操作负担**：固定操作栏；最小下注、2BB、半池快捷金额，自动校验合法范围；全下确认。验收：无需滚屏找按钮，按钮同时显示“投入多少/剩余多少”。
3. **增强针对性复盘**：标注主池/边池、最佳5张牌、决策快照与重练按钮；分开规则事实、数学结论和条件性建议。
4. **再提高模拟真实性**：电脑结合公共牌及位置，提供不同风格；保留仅使用公开信息的限制，用固定种子测试稳定性。

建议先做第1、2项，保持页面简单，暂不增加大型求解器、复杂统计仪表盘或联网能力。
