项目仓库：https://github.com/wenbofan0515-afk/holdem-trainer

先检查用户工作目录中是否已有该项目；没有时克隆到用户工作目录的 holdem-trainer 子目录，不覆盖已有文件。检查 Node.js 和 npm；建议 Node.js 22.12 或更新的 LTS。首次运行在项目目录执行 npm ci，然后 npm run dev -- --port 5173。保持服务进程运行，向用户提供 http://127.0.0.1:5173/；端口占用时使用 Vite 实际返回的地址，不终止其他服务。

只监听 127.0.0.1，不部署公网。数据存储在本机浏览器 localStorage，不会随 GitHub 同步到其他电脑。

当前支持完整一手的下注、摊牌派奖、复盘和继续下一手，练习仅 5 道。完整赛事最终排名积分未验收；电脑不是专业求解器，复盘不提供策略打分。前注、到点最后一手、同筹码排名仍为训练假设。旧版存档不兼容，新版刷新恢复时暂停且不重复扣盲。不要声称已完成最初计划的全部功能。
